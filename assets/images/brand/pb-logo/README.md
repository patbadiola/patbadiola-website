# PB logo files

Use SVG as the primary format and keep raster exports transparent.

Recommended filenames:

- `pb-logo-site.webp` — optimized square website logo currently used by the header and footer
- `favicon.ico` — multi-size browser-tab icon
- `favicon-32.png` — 32 x 32 browser favicon
- `apple-touch-icon.png` — 180 x 180 home-screen icon for Apple devices
- `pb-logo.svg` — primary full logo
- `pb-logo-dark.svg` — logo for light backgrounds
- `pb-logo-light.svg` — logo for dark backgrounds
- `pb-mark.svg` — compact PB symbol
- `pb-logo.webp` — optional transparent raster fallback

Use lowercase kebab-case and do not include spaces, dates, or version numbers in production filenames.
