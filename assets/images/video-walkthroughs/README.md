# Video walkthrough thumbnails

Store one optimized thumbnail for each video walkthrough in this folder or in a project subfolder.

Naming convention:

`<project-slug>-walkthrough-thumbnail.webp`

Recommended export:

- WebP
- 1600 x 1000 px
- 16:10 aspect ratio (16:9 is also acceptable)
- Lowercase kebab-case filenames
- Aim for less than 300 KB when image quality allows

Examples:

- `brightsmile-dental-crm-walkthrough-thumbnail.webp`
- `elite-realty-crm-walkthrough-thumbnail.webp`
- `pb-flow-crm-walkthrough-thumbnail.webp`
- `elite-realty-buyer-walkthrough-thumbnail.webp`
- `elite-realty-seller-walkthrough-thumbnail.webp`
- `elite-realty-home-valuation-walkthrough-thumbnail.webp`
- `elite-realty-property-showing-walkthrough-thumbnail.webp`
- `elite-realty-client-review-walkthrough-thumbnail.webp`
- `brightsmile-appointment-booking-walkthrough-thumbnail.webp`
- `brightsmile-patient-feedback-walkthrough-thumbnail.webp`

Elevate Academy thumbnails belong in the `elevate-academy` subfolder.
